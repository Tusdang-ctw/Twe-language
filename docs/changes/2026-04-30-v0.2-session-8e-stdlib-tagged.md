# 2026-04-30 — v0.2 Phase 8.5 session 8e: Object::fields + BcInstance::fields on TaggedValue

## Status: shipped. Fifth of nine sessions in the NaN tagging migration. Migrates the last two field-storage maps (`Object::fields` and `BcInstance::fields`) to `HashMap<String, TaggedValue>`. After 8e, every value-typed slot in the runtime — stack, globals, env, instance fields, object fields, BcInstance fields — lives in tagged form.

## Background

Sessions 8c and 8d migrated the VM hot path and the tree-walker's main data structures. Session 8e finishes the *storage* side of the migration — `Object` (every stdlib module: `math`, `key`, `mouse`, `screen`, `time`, `color`, `random`, `entities`, `tilemap`, `camera`, `sound`, `music`, `key_press`, `mouse_held`, `mouse_press`, plus user-defined Objects) and `BcInstance` (bytecode-VM instance fields) flip to `TaggedValue` storage.

The "every `Value::` in builtins becomes `TaggedValue::*`" rule from `docs/08-nan-tagging.md`'s 8e description is the *interior pattern-match* sweep — that work folds into 8f when the legacy `Value` enum deletes. Keeping 8e mechanical (storage migration only, shim at boundaries) holds the regression surface in line with what 8c–8d showed: low risk, high velocity, all 499 tests green.

## What ships

### `Object::fields` storage

```rust
pub struct Object {
    pub fields: HashMap<String, TaggedValue>,  // was HashMap<String, Value>
    pub kind: &'static str,
}
```

### `BcInstance::fields` storage

```rust
pub struct BcInstance {
    pub class: Rc<BcClassDef>,
    pub fields: HashMap<String, TaggedValue>,  // was HashMap<String, Value>
    ...
}
```

### Accessor helpers on Object / Instance / BcInstance

Every receiver-by-name access pattern goes through these:

```rust
impl Object {
    pub fn get_field(&self, name: &str) -> Option<Value> {
        self.fields.get(name).map(|t| t.clone().to_legacy())
    }
    pub fn insert_field(&mut self, name: impl Into<String>, value: Value) {
        self.fields.insert(name.into(), TaggedValue::from_legacy(&value));
    }
}
```

Identical impls on `Instance` and `BcInstance`. Most of the eval / vm / stdlib / play / play3d / test sites swept from direct `.fields.get(...)` / `.fields.insert(...)` to the new helpers via mechanical replace.

### `legacy_fields_to_tagged` for stdlib bootstrap

Stdlib's pattern is "build a HashMap with `Value` literals, hand off to `Object::fields` at construction":

```rust
pub fn legacy_fields_to_tagged(
    legacy: HashMap<String, Value>,
) -> HashMap<String, TaggedValue> {
    legacy.into_iter()
        .map(|(k, v)| (k, TaggedValue::from_legacy(&v)))
        .collect()
}
```

Used at every `Object { fields: SOMENAME, kind: ... }` construction in `stdlib.rs` (17 sites — math, key_press, mouse, sound, music, color, screen, random, time, camera, tile_specs, etc.) and at the corresponding sites in `save.rs` / `tagged_value.rs::tests`.

### Save shim through `to_legacy()`

`save::encode` iterates `&o.fields` and converts each `&TaggedValue` to `Value` for the recursive encode call:

```rust
for (k, v) in &o.fields {
    map.insert(k.clone(), encode(&v.clone().to_legacy())?);
}
```

`save::decode` builds a `HashMap<String, Value>` imperatively and converts at the `Object { ... }` boundary via `legacy_fields_to_tagged`.

## Not in scope

- **Pattern-match sweep across stdlib / eval / vm interiors** — the doc's "every `Value::` becomes `TaggedValue::*`" rule is the 8f rewrite. ~917 `Value::` pattern-match sites across the codebase as of post-8e; each is mechanical (`match v { Value::Int(n) => ... }` → `if v.is_int() { let n = v.as_int(); ... }`) but the volume is genuinely a multi-session sub-phase on its own.
- **`ClassDef::field_defaults` / `BcClassDef::field_defaults`** — AST-time constant pools, no urgency. Folds into 8f.
- **`Frame::saved_returning` / `Frame::saved_params`** on suspended fibers — same.

## Migration scoreboard

After 8e, all runtime *storage* of values is on `TaggedValue`:

| Slot                                | Migrated in |
|-------------------------------------|-------------|
| `vm.stack`                          | 8c          |
| `vm.globals`                        | 8c          |
| `BcInstance.fiber_stack` (suspended)| 8c (shimmed)|
| `Env::bindings`                     | 8d          |
| `Instance::fields`                  | 8d          |
| `Object::fields`                    | 8e          |
| `BcInstance::fields`                | 8e          |
| `ClassDef::field_defaults`          | 8f (deferred — AST const pool) |
| `BcClassDef::field_defaults`        | 8f (deferred — AST const pool) |

The remaining 8f work is the *pattern-match interior* rewrite, which the storage migration was designed to enable: every `match v { Value::X(...) }` site can rewrite to `TaggedValue` predicates without forcing storage churn at the same time.
