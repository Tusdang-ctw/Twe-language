The game starts in the "playing" mode. While playing, a timer counts the
seconds played. Escape pauses the game ("paused"; the timer stops) and
Escape again resumes it. While paused, Q asks whether to quit
("confirm_quit"); then Y quits to the title screen ("title") and N goes
back to "paused". On the title screen, Enter starts a new game: the
timer goes back to 0 and the mode is "playing".
