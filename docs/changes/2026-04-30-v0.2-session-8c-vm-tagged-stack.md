# 2026-04-30 — v0.2 Phase 8.5 session 8c: VM stack + globals on TaggedValue

## Status: shipped. Third of nine sessions in the NaN tagging migration. Migrates the bytecode VM's value stack and globals table to `TaggedValue` storage; expands the `from_legacy` / `to_legacy` shim to round-trip every `Value` variant via the heap.

## Background

Sessions 8a / 8b shipped the standalone `TaggedValue` module + the heap-body expansion that covers the common Twe value variants. Session 8c is the first session to *consume* that foundation — the bytecode VM's hot data path (the value stack, the dispatch loop's locals, and the globals map) flips to `TaggedValue` storage with `to_legacy()` / `from_legacy()` shimming at the pattern-match boundary.

Per `docs/08-nan-tagging.md` "Migration sequencing", 8c keeps the dispatch loop's existing pattern matches on legacy `Value` — the deeper match-arm rewrite to `TaggedValue` predicates folds into 8f when the legacy enum deletes. That's the same risk-minimising posture the design doc names: `BcInstance` "stays on legacy `Value` internally for now (its fields are user-visible); `to_legacy` / `from_legacy` at the field-access boundary."

## What ships

### `TaggedValue` storage in `src/vm.rs`

```rust
pub struct VM {
    stack: Vec<TaggedValue>,            // was Vec<Value>
    frames: Vec<CallFrame>,
    globals: HashMap<String, TaggedValue>,  // was HashMap<String, Value>
    ...
}
```

The dispatch-loop `match` arms still consume `Value`. The conversion happens at four chokepoints — the existing `push` / `pop` / `pop_n` helpers (which were already there for stack manipulation) plus three new helpers added this session:

```rust
fn push(&mut self, v: Value)              // wraps TaggedValue::from_legacy(&v)
fn pop(&mut self) -> Result<Value, ...>   // unwraps t.to_legacy()
fn pop_n(&mut self, n: usize, ...)        // drain + map(.to_legacy())
fn slot_get(&self, abs: usize) -> Option<Value>     // NEW
fn slot_set(&mut self, abs: usize, v: Value)        // NEW
fn peek_top(&self) -> Option<Value>                 // NEW
```

`OP_GETLOCAL`, `OP_SETLOCAL`, `OP_FORNEXT`, `OP_JUMPIF*PEEK` swept to use the new helpers. Direct `self.stack[idx].clone()` reads convert via `.clone().to_legacy()` at the read site.

### Globals path

`OP_GETGLOBAL` reads a `TaggedValue` directly (no shim), pushes it raw onto the stack — no round-trip through `Value` for this hot path.

`OP_SETGLOBAL` and `OP_DEFINEGLOBAL` similarly: pop a `TaggedValue` directly, insert into globals.

`vm.get_global(name)` keeps its public `Option<Value>` signature for callers (play loop input handlers, tests) — converts internally.

### `OP_WAIT` fiber save

`BcInstance::fiber_stack` stays on `Vec<Value>` (per the design's "BcInstance stays on legacy Value internally"). `OP_WAIT` converts the slice from `&[TaggedValue]` to `Vec<Value>` element-wise on save; `resume_state_entry` converts back via `extend(saved.into_iter().map(|v| TaggedValue::from_legacy(&v)))`.

### Full-Value shim coverage

Session 8a / 8b's shim only covered primitives + the heap variants 8b added. `Value` has 17 variants total, and the VM stack can hold any of them — `BcFunction`, `BcClass`, `BcInstance`, `Builtin`, `Class`, `Instance`, `Function` were not yet shimmable.

Session 8c expands `HeapBody` with the missing variants:

```rust
pub enum HeapBody {
    String(String),
    BoxedInt(i64),
    Percent(f64),
    Quantity { value: f64, unit: Rc<String> },
    Range { start: i64, end: i64, exclusive: bool },
    Tuple(Rc<Vec<Value>>),
    List(Rc<RefCell<Vec<Value>>>),
    Object(Rc<RefCell<Object>>),
    Class(Rc<ClassDef>),                    // NEW (8c)
    Function(Rc<FunctionDef>),              // NEW (8c)
    Instance(Rc<RefCell<Instance>>),        // NEW (8c)
    BcFunction(Rc<crate::bytecode::BcFunction>),  // NEW (8c)
    BcClass(Rc<crate::bytecode::BcClassDef>),     // NEW (8c)
    BcInstance(Rc<RefCell<crate::bytecode::BcInstance>>),  // NEW (8c)
    Builtin {
        name: &'static str,
        params: &'static [&'static str],
        func: crate::value::BuiltinFn,
    },                                      // NEW (8c)
}
```

`HeapBodyKind` gains the matching seven variants. `from_legacy(&Value::X(...))` and `to_legacy()` now round-trip every variant — heap variants share their existing `Rc` (no deep copy).

### Tests

2 new tests in `src/tagged_value.rs::tests` (24 total now, up from 22):

- `legacy_shim_round_trips_heap_variants` — exercises Tuple / List / Quantity round-trip, asserts shared-Rc semantics (no deep copy).
- `legacy_shim_round_trips_bc_function` — `Rc::ptr_eq` after round-trip pins the shim's identity-preservation contract.

## Not in scope

- **`Env::bindings` / `Instance::fields` migration** — session 8d.
- **`Object::fields` / `BcInstance::fields` migration** — session 8e.
