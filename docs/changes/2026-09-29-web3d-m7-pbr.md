# web3d-M7 session 3: physically based materials

**Date:** 2026-09-29
**Milestone:** web3d-M7 ([scope](2026-09-28-web3d-m7-graphics-beyond-threejs.md), [sessions](2026-09-29-web3d-m7-plan.md), [baseline](2026-09-29-web3d-m7-baseline.md))
**Code:** `src/kernel/material.rs` (new); the loader, shader and draw loop in `src/kernel/render.rs`

## What changed

1. **Tone curve.** Twe's tonemap used Narkowicz's one-line ACES approximation. It now uses the fitted ACES Filmic curve (RRT + ODT in AP1, 1/0.6 exposure), which is what Three.js, the glTF Sample Viewer and the Cycles references apply. Scored on its own first.
2. **Materials per glTF primitive.** The loader used to flatten a model and texture all of it with the first material's base colour. Now each primitive is a *submesh* drawn with its own material:
   - metallic-roughness factors and their five textures: base colour, metal-rough, normal, occlusion, emissive;
   - `KHR_texture_transform` on every texture, including normal and occlusion, which the `gltf` crate only exposes as raw JSON;
   - `KHR_materials_emissive_strength`;
   - glTF samplers (wrap and filter);
   - the second UV set, alpha mask, and double-sided surfaces (a second pipeline without back-face culling);
   - glTF's default material for primitives that name none.

   Colour textures upload as sRGB, data textures as linear.
3. **Vertex data:** `TEXCOORD_1`, `TANGENT` and `COLOR_0` join the vertex (stride 56 → 96 bytes).
4. **Shading** (`shade` in `SHADER_SRC`), per glTF Appendix B:
   - Lambert diffuse, plus Cook-Torrance specular (GGX, height-correlated Smith visibility, Schlick Fresnel);
   - multiscatter energy compensation (Fdez-Agüera 2019), using Karis's analytic DFG fit until session 4 brings a LUT;
   - normal maps in the vertex tangent frame, or a screen-space-derivative frame when the model has no tangents (Schüler 2013, as Three.js does);
   - occlusion on indirect light only; emission.

   One function shades glTF materials, the plain surface, and `visual` materials.
5. **The game's own shapes** (cubes, spheres, script textures) use a plain dielectric material (roughness 0.5). Light units are chosen so existing lights keep their brightness: intensity 1 on white Lambert reflects 1. The camera uniform now carries the eye position.

There's no new language surface: `look:` and `mesh()` are unchanged, and glTF models simply look like glTF models now.

## What's still missing, per scene

A side-by-side of the three worst scenes shows the remaining error is almost all **lighting from the environment**, not surfaces:
- **MetalRoughSpheres and IridescenceLamp:** the environment is the visible backdrop, and Twe draws black. Metals reflect a flat ambient colour instead of the scene.
- **TextureTransformTest:** every transformed texture now lands exactly where the reference has it; the colours are washed out by Twe's default sun + ambient lighting.
- **IridescenceLamp's glass:** renders opaque. That's transmission, session 10.

That is session 4, **image-based lighting**:
- HDR environments loaded;
- GPU-prefiltered specular, SH irradiance, a real DFG LUT;
- the environment as backdrop.

It should move every scene.
