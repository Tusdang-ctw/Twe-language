# web3d-M7 plan: sessions

**Opened:** 2026-09-29
**Milestone:** web3d-M7, graphics beyond Three.js ([scope and exit criteria](2026-09-28-web3d-m7-graphics-beyond-threejs.md))

**Method:** measure first. Session 2 builds the Three.js comparison harness *before* the renderer changes, so every feature after it lands with a before/after ꟻLIP number, not a screenshot and a claim. Each session keeps the frame byte-identical where it isn't changing it, and adds a headless render test for what it adds (exit criterion 4).

## Sessions

1. **Render graph.** Done 2026-09-29 ([design note](2026-09-29-web3d-m7-render-graph.md)).
   - Passes and targets are declared per frame.
   - Culling, validation, aliased transient textures.
   - The existing frame ported, output byte-identical.
2. **The comparison harness** (`bench/graphics/`). Done 2026-09-29 ([baseline](2026-09-29-web3d-m7-baseline.md)): Twe 0.348 mean ꟻLIP against Three.js 0.186.
   - pinned glTF Sample Assets and a pinned Three.js release;
   - per-scene camera, environment and exposure specs;
   - Twe rendered headless natively, and Three.js through headless Chrome (Playwright), from the same spec;
   - ꟻLIP against the fidelity project's path-traced (Blender Cycles) references;
   - one command writing a results table (`bench/graphics/results.md`).

   First numbers are M7's baseline, where Twe is expected to lose.
3. **Physically based shading.** Done 2026-09-29 ([note](2026-09-29-web3d-m7-pbr.md)): mean ꟻLIP 0.348 → 0.295 (Three.js 0.186).
   - glTF metallic-roughness (GGX, multiscatter energy compensation);
   - normal, occlusion, emissive and metal-rough maps;
   - vertex colours, `KHR_texture_transform`;
   - materials read per glTF primitive, where today only base colour is.
4. **Image-based lighting.** Done 2026-09-29 ([note](2026-09-29-web3d-m7-ibl.md)): mean ꟻLIP 0.295 → 0.198 (Three.js 0.186); also fixed flat normals for normal-less glTF primitives.
   - HDR environment loading;
   - GPU-prefiltered specular mips, spherical-harmonic irradiance, a BRDF LUT;
   - sky and environment as scene settings (language-surface note if a key is needed).
5. **Anti-aliasing:** 4× MSAA first, then TAA with motion vectors (history as an imported graph texture).
6. **Shadows:**
   - cascades fitted to the view frustum;
   - PCSS soft shadows;
   - spot and point light shadows.
7. **Post, part 1:**
   - GTAO (depth prepass);
   - multi-level physically based bloom;
   - manual and auto exposure;
   - AgX and Khronos PBR Neutral tonemappers.
8. **Post, part 2:** colour-grading LUTs, depth of field, motion blur.
9. **Transparency and atmosphere:** sorted blending with weighted-blended OIT fallback, exponential height fog.
10. **glTF material extensions:**
    - clearcoat, transmission + volume, sheen, iridescence, anisotropy, emissive strength, IOR, specular;
    - KTX2 / BasisU textures and meshopt geometry.

    Tier 1 closes here; every glTF scene gets its ꟻLIP row.
11. **GPU-driven rendering:** compute frustum + hierarchical-Z occlusion culling, indirect draws.
12. **Clustered forward lighting:** hundreds of lights, shadow budget.
13. **GPU compute particles:** 1M, depth-buffer collision, driven by `particles` blocks.
14. **Screen-space reflections; volumetric fog with light shafts.**
15. **Procedural surface materials:** `visual` blocks gain albedo / normal / roughness / metalness / emission outputs, vertex displacement and world-space inputs. This is a language change, with a design note, an example, `docs/06`, and the full tooling path.
16. **`survive3d` uses it all:**
    - PBR, IBL, AA, AO and bloom on;
    - one look authored purely as a procedural material;
    - the 100k-instance / 500-light / 1M-particle stress scene;
    - 60 fps checks in Chrome.
17. **Publish and close:** comparison images, ꟻLIP table and frame times against the pinned Three.js; the closeout note says where Twe loses.

## Rules for this milestone

- **Commits:** `web3d-m7:`. Closeout note at the end.
- **Language surface:** grows only with an example and a design note (M7 plan rule 3).
- **Honest scoring:** a feature is "done" when its scenes' ꟻLIP rows and render tests exist, not when it looks right.
