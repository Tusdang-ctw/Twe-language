Make a top-down game in which the player starts at the origin and moves
across the ground plane while direction keys are held, at 5 units per
second along each axis:

- D moves it toward +x, A toward -x;
- S moves it toward +z, W toward -z.

Keys on different axes combine (A and S together move it diagonally);
it never leaves the ground (y stays 0). With no key held it stays where
it is. Draw the player so it can be seen.
