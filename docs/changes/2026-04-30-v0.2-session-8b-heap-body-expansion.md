# 2026-04-30 — v0.2 Phase 8.5 session 8b: HeapBody expansion

## Status: shipped. Second of nine sessions in the NaN tagging migration. Expands `HeapBody` from `String`-only (session 8a) to cover BoxedInt + Percent + Quantity + Range + Tuple + List + Object, plus the `HeapBodyKind` discriminator that the GC's mark phase will key off.

## Background

Session 8a shipped the standalone `TaggedValue` foundation with a single-variant `HeapBody::String`. Session 8b expands the heap representation to cover the commonly-used Twe value variants, plus the i48-overflow boxed-int path that 8a explicitly deferred.

Function / BcFunction / Class / BcClass / Instance / BcInstance / Builtin variants stay deferred to session 8c+ — they're tightly coupled to eval/vm and migrate alongside their callers.

## What ships

### Expanded `HeapBody`

```rust
pub enum HeapBody {
    String(String),                                                       // 8a
    BoxedInt(i64),                                                        // NEW
    Percent(f64),                                                         // NEW
    Quantity { value: f64, unit: Rc<String> },                            // NEW
    Range { start: i64, end: i64, exclusive: bool },                      // NEW
    Tuple(Rc<Vec<crate::value::Value>>),                                  // NEW
    List(Rc<RefCell<Vec<crate::value::Value>>>),                          // NEW
    Object(Rc<RefCell<crate::value::Object>>),                            // NEW
    Reserved8c,                                                           // placeholder
}
```

Collections (Tuple / List / Object) currently hold legacy `Value` interiors. Sessions 8c–8e migrate the inner `Vec<Value>` to `Vec<TaggedValue>` as their consumers move; for now the Rc-shared legacy interior lets `from_legacy` / `to_legacy` shim cheaply.

### `HeapBodyKind` discriminator

```rust
pub enum HeapBodyKind {
    String, BoxedInt, Percent, Quantity, Range, Tuple, List, Object,
}
```

Used by `TaggedValue::is_obj_body_kind(kind)` for fast "what kind of object is this?" predicates without paying for a `with_obj_body` closure. Session 8g's `HeapHeader` will cache this discriminator on each heap object so the GC's per-body-type mark dispatch is one indexed table lookup.

### Smallint overflow → BoxedInt

`TaggedValue::from_int(n: i64)`:

- If `n` is in the i48 range (`[-2^47, 2^47 - 1]`), takes the immediate fast path (TAG_INT + 48-bit payload).
- Otherwise heap-allocates `HeapBody::BoxedInt(n)` (TAG_OBJ).

Replaces session 8a's silent truncation. `TaggedValue::as_int()` now branches on `is_int()` vs the boxed case; new `is_int_or_boxed_int()` helper is the canonical "is this an integer regardless of representation" predicate.

### New constructors

```rust
TaggedValue::from_percent(p: f64) -> Self
TaggedValue::from_quantity(value: f64, unit: Rc<String>) -> Self
TaggedValue::from_range(start: i64, end: i64, exclusive: bool) -> Self
TaggedValue::from_tuple(elems: Rc<Vec<Value>>) -> Self
TaggedValue::from_list(elems: Rc<RefCell<Vec<Value>>>) -> Self
TaggedValue::from_object(obj: Rc<RefCell<Object>>) -> Self
```

Each routes through a private `from_heap(body: HeapBody)` that allocates `Rc<HeapObject>`, calls `Rc::into_raw`, packs the pointer into `TAG_OBJ | (raw & PAYLOAD_MASK)`. The `TaggedValue::Drop` impl from 8a already balances the refcount when the value drops.

### Inspection API

```rust
v.with_obj_body(|body| match body { ... })  // closure-style match-on-variant
v.is_obj_body_kind(HeapBodyKind::List)       // discriminator predicate
```

`as_string` (8a) is retained for the common Str case; other variants use `with_obj_body` for now. Session 8c+ may add type-specific extractors as migration patterns emerge.

### Tests

9 new tests in `src/tagged_value.rs::tests` (22 total now):

- `boxed_int_round_trip_above_i48` / `below_i48` — verify the boxed path fires + round-trips.
- `percent_round_trip` — `from_percent` + `is_obj_body_kind(Percent)` + `with_obj_body` extraction.
- `quantity_round_trip` — value + unit string round-trip.
- `range_round_trip` — start / end / exclusive round-trip.
- `tuple_round_trip_holds_legacy_values` — Tuple of Value::Int round-trips.
- `list_round_trip_holds_mutable_legacy_values` — List shares its `Rc<RefCell<...>>` with the constructor; mutations through the original Rc are visible to the TaggedValue.
- `object_round_trip_carries_kind_string` — `Object::kind` round-trips.
- `heap_body_kind_classifies_each_variant` — pin every `HeapBodyKind::of` mapping.

## Not in scope

- **Function / BcFunction / Class / BcClass / Instance / BcInstance / Builtin** — session 8c (alongside the VM migration that consumes them).
- **`HeapHeader` with mark bits** — session 8g (when the GC allocator lands).
- **Migration of any existing call sites** — sessions 8c–8e mechanically rewrite eval / vm / stdlib to use TaggedValue.
