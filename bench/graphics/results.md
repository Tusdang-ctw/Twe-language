## Notes

- **Sponza:** the Cycles reference is lit only by sky through the courtyard opening, so the colonnades are dark; engines without occlusion light them far too brightly. Twe's lead here (since M7 session 7) comes from ambient occlusion, which the harness turns on for Twe; Three.js as the harness renders it has none (three ships a GTAOPass addon, not used here). The error is still large for every engine.
