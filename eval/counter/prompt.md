# Task: Frame-counting `on update` loop

Write a Twe program that counts elapsed frames using a top-level
`on update(dt):` handler.

## Constraints

- Declare a `var n = 0` at top level.
- In `on update(dt):` increment `n` by one and `print(n)`.
- After 5 frames, the program will have printed `1`, `2`, `3`, `4`, `5`
  (each on its own line).

## Output

Reply with **only** a single ```twe fenced block. No commentary
outside the fence.
